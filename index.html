About

Design and code
are the same job.

I don't hand a spec off and I don't hand a design off. I define the product, draw the interface, model the data behind it, and write the code that makes it real - so the decisions hold up all the way down.

That shows up in small places. In Auticket the appeal button sits beside the pay button instead of three screens deep, because a citizen who can't find it calls the municipality. In Midrash.live a physical class is its own entity, not a video, because forcing it into the video model would have broken search. In Strata the owners' signatures are a bar with the legal threshold drawn on it, because “are we there yet?” is the only question anyone asks.

I work in Hebrew and English, right‑to‑left and left‑to‑right, on the web, on native mobile and in WebGL.
